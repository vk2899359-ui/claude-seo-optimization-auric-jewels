## High-Opportunity Keyword Gaps (Auric Jewels Can Win)

### Zero Competitor Coverage (Wide Open)
- "custom diamond jewellery gurgaon" — No named competitor ranks
- "anniversary gift jewellery gurgaon" — Only gift delivery sites rank
- "men's diamond jewellery gurgaon" — Only Emori (lab-grown) appears
- "polki kundan bridal set gurgaon" — No major competitor

### Weak Competitor Coverage (Beatable)
- "solitaire ring price gurgaon" — Only small local players rank
- "engagement ring gurgaon" — BlueStone/Kalyan weak, directories dominate
- "karva chauth jewellery gurgaon" — Only BlueStone product page
- "platinum jewellery gurgaon" — SS Jewellers homepage only

### Informational Gaps (Blog Opportunities)
- "solitaire vs diamond ring" — Only CaratLane blog ranks
- "hallmark gold jewellery guide" — Finance sites dominate, no jeweller blogs
- "how to choose diamond mangalsutra" — No competitor has a guide
- "gold rate today gurgaon buying tips" — Only rate trackers, no buying advice

## Priority Recommendation
Focus on CUSTOM + OCCASION + BUYING GUIDE keywords. These have:
1. High buying intent (BoFU)
2. Low competition from named jewellers
3. Strong local (Gurgaon/Delhi NCR) relevance
4. Natural product page linking opportunities
